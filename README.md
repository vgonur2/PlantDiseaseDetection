# Plant Disease Detection (LeafGuard)

The Next.js web app lives in the **`web/`** folder.

## Run locally

From the repository root:

```bash
npm run dev
```

Or from `web/`:

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy (Vercel)

Set the project **Root Directory** to `web`, or use the included `vercel.json` at the repo root (it builds from `web/` automatically).
